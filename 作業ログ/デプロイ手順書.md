# 副業キャリアナビ デプロイ手順書

## 全体の流れ

```
GitHub リポジトリ作成
     ↓
ファイルをプッシュ
     ↓
Cloudflare Pages でビルド設定
     ↓
Cloudflare でドメイン取得
     ↓
ドメインを Pages に割り当て
     ↓
A8.net / もしもアフィリエイト でリンク取得・記事に貼る
```

---

## STEP 1：GitHubアカウントを確認 / 作成

1. https://github.com を開く
2. ログインできれば OK
3. ログインできない場合は「Sign up」から無料アカウントを作成

---

## STEP 2：GitHubにリポジトリを作成

1. GitHub にログイン後、右上の「+」→「New repository」
2. 設定：
   - Repository name: `fukugyo-career-navi`
   - Visibility: **Public**（Cloudflare Pages 無料枠はPublicが必要）
   - Initialize: チェックしない
3. 「Create repository」をクリック

---

## STEP 3：ファイルをGitHubにプッシュ

Claude Code のターミナルで以下を実行：

```bash
cd "D:/murahata/SOFT,APP/ClaudeCode/出力用フォルダ/affiliate-blog"
git init
git add .
git commit -m "Initial commit: 副業キャリアナビ"
git branch -M main
git remote add origin https://github.com/【あなたのGitHubユーザー名】/fukugyo-career-navi.git
git push -u origin main
```

※ `【あなたのGitHubユーザー名】` を自分のユーザー名に変更してください。

---

## STEP 4：Cloudflare Pages に接続

1. https://dash.cloudflare.com にログイン（なければ無料登録）
2. 左メニュー「Workers & Pages」→「Pages」→「Create a project」
3. 「Connect to Git」→ GitHub を連携
4. `fukugyo-career-navi` リポジトリを選択
5. ビルド設定：

| 項目 | 設定値 |
|------|--------|
| Framework preset | Astro |
| Build command | `npm run build` |
| Build output directory | `dist` |
| Node.js version | `20` |

6. 「Save and Deploy」をクリック
7. 数分待つとデプロイ完了 → `https://fukugyo-career-navi.pages.dev` でアクセス可能

---

## STEP 5：Cloudflare でドメインを取得

1. Cloudflare ダッシュボード → 左メニュー「Domain Registration」→「Register Domains」
2. 取得したいドメイン名を検索（例：`fukugyo-career-navi.com`）
3. 購入（年間約1,500〜2,000円が目安）
4. 購入後、左メニュー「Workers & Pages」→ 作成したPagesプロジェクト
5. 「Custom domains」→「Set up a custom domain」
6. 購入したドメインを入力 → 自動でDNS設定される

---

## STEP 6：ASP登録 ─ アフィリエイトリンクを取得

### A8.net への登録

1. https://www.a8.net にアクセス → 「メディア登録」
2. ブログURLに `https://あなたのドメイン.com` を入力
3. 登録後、以下の案件に申し込む：
   - 「リクルートエージェント」で検索
   - 「doda」で検索
   - 「TECH CAMP」で検索
   - 「DMM WEBCAMP」で検索

### もしもアフィリエイトへの登録

1. https://af.moshimo.com にアクセス → 登録
2. 物販系（Amazon/楽天）のリンクも使える

---

## STEP 7：記事にアフィリエイトリンクを貼る

各記事の「※アフィリエイトリンクを設置予定」箇所を実際のリンクに差し替えます。

**例（A8.netのテキストリンク）：**
```markdown
<a href="https://px.a8.net/svt/ejp?a8mat=【取得したコード】" rel="nofollow">
  リクルートエージェントに無料登録する →
</a>
```

差し替えが完了したら git push するだけで自動デプロイされます：
```bash
git add .
git commit -m "アフィリエイトリンクを追加"
git push
```

---

## 記事追加の方法

新しい記事を追加したい場合：

1. `src/content/blog/` フォルダに新しい `.md` ファイルを作成
2. 先頭に以下のフロントマターを記入：

```markdown
---
title: "記事タイトル"
description: "記事の説明（検索結果に表示されます）"
pubDate: 2026-05-01
category: tensha  # tensha / programming / fukugyo のいずれか
tags: ["タグ1", "タグ2"]
affiliate: true
---

記事本文をここに書く
```

3. `git add . && git commit -m "新記事追加" && git push` で公開完了

---

## ドメイン変更後の対応

ドメインが決まったら `astro.config.mjs` の `site` を更新：

```js
site: 'https://取得したドメイン.com',
```

同様に `public/robots.txt` の Sitemap URL も更新してください。
